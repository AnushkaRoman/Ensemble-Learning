# Advanced Ensemble Learning and Performance Evaluation

## Project Description

This project implements and evaluates advanced ensemble learning techniques using Python and Scikit-learn. The Breast Cancer Wisconsin Diagnostic Dataset is used for binary classification.

## Algorithms Implemented

### Base Classifiers
- Logistic Regression
- Decision Tree
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)
- Gaussian Naive Bayes

### Ensemble Techniques
- Stacking Ensemble
- AdaBoost Ensemble
- Hard Voting Ensemble
- Soft Voting Ensemble
- Random Forest (Bagging)

## Performance Evaluation

The models are evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC
- Log Loss
- Inference Latency

## Visualizations

- Confusion Matrices
- ROC Curves
- Performance Metrics Comparison
- AdaBoost Error Trajectory
- Stacking Meta-Classifier Weights
- PCA Decision Boundaries
- Log Loss vs Inference Latency

## Technologies Used

- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset

Breast Cancer Wisconsin Diagnostic Dataset from Scikit-learn.

## Execution

The project can be executed using Google Colab by opening the `.ipynb` notebook and running all cells sequentially.
